# mdviewy Benchmark - 2026-09-17

Environment:
- macOS host, Apple Silicon aarch64 release build (fat LTO)
- Version: 0.101.0, installed at `/Applications/mdviewy.app`
- Measured after the post-review hardening wave (security + data-loss fixes)

Results:
- Frontend production build: `11.03s` (Vite, 8230 modules)
- Tauri release compile: `1m 07s` (warm cache)
- `just install` end-to-end: ~`1m 10s`
- Release binary size: `15,044,592 B` (~15.0 MB, was 20 MB at 0.55.x)
- Installed `.app` size: `15M`
- Frontend `dist`: `13M`
- Boot to window (`window built at` log): 8 samples —
  `64, 53, 53, 61, 58, 51, 55, 59 ms` → median ~`57 ms`
- Idle RSS after 3s: `~104 MB`

Largest frontend chunks (minified):
- `createMdviewyWysiwygDelegate` 2.78 MB (remirror/WYSIWYG, lazy)
- `index-DIzDW56p` 1.07 MB, `index-BJsswcOs` 843 kB
- `wardley` 612 kB, `cytoscape` 442 kB, `pdf` 407 kB (all lazy)

Heavy crates confirmed absent from the binary: tantivy, syntect,
comrak, zhconv (removed with the dormant `mdviewy-core` feature path).

Verification gates (all green at measurement time):
- `cargo fmt --check`, `cargo check`, `clippy -D warnings`: pass
- `cargo nextest`: 31/31 pass, 2 skipped
- `cargo audit`: 0 vulnerabilities; 12 allowed warnings (unmaintained/
  platform-transitive, documented in `docs/adr/2026-06-05-security-posture-1.0.md`)
- Frontend: `tsc --noEmit` clean; vitest 45 files / 185 tests pass;
  `yarn build` clean

Known remaining headroom:
- Boot path performs several synchronous config reads; the 2.78 MB
  WYSIWYG chunk is already lazy but dominates total bundle weight.
- Fonts are not subsetted; Tauri devtools flag not audited for release.
